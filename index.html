ACADEMIC

Tom & Jerry Embedded System

C, C++, STM32, DE2 FPGA, Verilog, UART

// Overview

Architected a gamified embedded system utilizing STM32 microcontrollers and a DE2 FPGA, enabling real-time coordination between an autonomous robot (Jerry) and a PS2 controller-driven robot (Tom). The system integrates a dedicated computer vision pipeline via a Raspberry Pi 3B and PiCam to process visual data, driving custom wireless game logic and rendering a live arena visualization over VGA.

// Key Features

  • Autonomous Navigation & Firmware: Developed motor control and state-machine firmware for the autonomous robot using PWM-driven outputs and I2C time-of-flight sensors for real-time wall avoidance, establishing a framework that also powered the controller-driven robot.
  • Computer Vision Pipeline: Configured a Raspberry Pi 3B and Pi See3Cam utilizing OpenCV to process real-time AprilTag detection, calculating precise spatial XY coordinates across the physical arena.
  • Custom Wireless Communication: Engineered a robust UART wireless protocol utilizing ESP32 modules to transmit coordinate data and state commands between the vision pipeline, the robots, and the central hub.
  • Hardware-Accelerated Gamification: Interfaced an STM32 central hub with a DE2 FPGA to process game states, orchestrate the multi-node network, and render real-time graphics over a VGA display.
